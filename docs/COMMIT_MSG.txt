Judge any /v1/systemone server, calibrate it, and replay logs (D23-D25)

D23: the judge backend is any /v1/systemone-compatible server (e.g.
jev-rs on llama-server), not only api.typesafe.ai. The backend keeps the
name "jev" (no alias). New [judge] keys:

- expected_model (default "jev-1.13.0") replaces the hard-coded
  PINNED_MODEL check: a response reporting another model is a D15 failure
  (ask plus an error record). It is a tunable, validated on its own (an
  empty or padded name falls back with an error), fingerprinted, listed in
  `config`, and written commented by `config --init`. The constant is now
  client::DEFAULT_EXPECTED_MODEL. The load-time warning about judge.model
  is gone. A non-default expected_model without a calibration file warns.
- api_key_required (default true): false makes a missing key fine and sends
  no Authorization header. A key that is found is still sent. It is a
  transport setting like timeout_ms (shown in `config`, written by
  `--init`).

Every judge record logs backend_host (host:port of base_url, never
userinfo), expected_model and the reported model. The judge error record
carries backend_host.

D24: optional per-axis calibration, `[judge] calibration_file` (JSON,
format "cancelli-calibration/1": rubric_hash, model, fitted_at, source,
axes{id: {type, method, params, n, metrics?}}). noul answers use Platt
(p' = sigmoid(a*logit(p)+b)), choice and score answers a temperature on the
log-probabilities, renormalised (score = sum k*p'_k, choice = argmax).
`method` is a serde tag, so isotonic can be added later. Calibration
applies after the completeness check and before signal extraction
(jev::evaluate). The file is validated at load against the rubric in use
and expected_model, and per call against the reported model. An
unreadable, invalid or mismatched file refuses calibration: a config error
record, and every judge call asks with a judge error record. Uncalibrated
answers are never used silently. The record keeps the raw `answers` and
adds `answers_calibrated` and `calibration{file, sha, rubric_hash, model,
fitted_at, axes}`. calibration_file is fingerprinted by the file's sha256.

`cancelli calibrate --reference <files...> --out <file>` fits the file from
tte run rows, cancelli judge records (Jev answers + state; the configured
backend is queried with each state and exactly the questions Jev answered)
or pair lines (--offline; --pairs-out writes them for refitting). Platt
minimises cross-entropy against Jev's p as a soft target (Newton); the
temperature minimises the summed KL (golden section over 1/t). A fixed
seeded split (--holdout 0.25, --seed 42) fits on one part and reports
Brier and ECE before->after on the held-out part only. Items from another
rubric, non-Jev references and duplicate states are skipped and counted.
Online calibration refuses to run while expected_model is jev-1.13.0.

D25: `cancelli eval --logs <files...> --config <path> [--offline] [--json]`
replays logged calls through hook::evaluate_call, the hook's own decision
function (split out of hook::run, which now only parses, writes and
prints). Only the judge differs: eval::ReplayJudge reuses the logged answers
when the state, rubric and backend (host + expected_model) are unchanged,
otherwise resends the logged state, or rebuilds the state from the
transcript for calls that newly reach the judge. --offline never queries
and never reads the key. Truncated non-Bash inputs without a logged state
are reported as "input truncated". Older records (no final/would_emit,
stub-era unadjudicated, pre-D23 records without backend_host) get a
best-effort old decision noted in `why`. Output: summary, old->new
transition matrix, and the changed calls sorted by time with reasons (CARE
mode/verdict/score/skip/rules, newly/no longer judged, tier, calibration,
answer source). --json prints one object per record plus a summary line.
config::load_from loads an explicit config path; its default key file is
next to that path. transcript::parse ignores records after the current
tool_use, so rebuilt states only see what preceded the call (hook states
are unchanged: at hook time the call is not yet written).

Tests: tests/local_backend.rs (8) drives the real binary against a local
replay server serving real cached jev-1.13.0 answers as "qwen-local": the
expected model is accepted and a different one asks with an error record;
no key means no Authorization header, and a present key is still sent;
config/--init/fingerprint/validation of the new keys; calibration moves f5
and the tier both ways (T6->T2 deny, T5->T6 allow); mismatched model or
rubric, invalid JSON and a missing file each ask with config and judge
error records; calibrate --offline recovers Platt(1.5, -0.7) and t = 0.6
from synthetic pairs within 0.01 with lower held-out Brier/ECE; and online
calibrate queries the server for tte rows and a log record, then refits
the saved pairs offline to the same parameters. tests/eval_e2e.rs (5): a
hook-written log plus older-format records gives exact transitions under a
modified config offline, with the replay server (a rebuilt state is sent),
and against a different backend (the logged states are resent verbatim).
The same config replays with no change, and the text output is sorted and
stable. Unit tests cover the calibration file, the transforms, the fitters,
metrics, the seeded shuffle, host_of, truncation detection, old-decision
inference and the transcript cut-off.
